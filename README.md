# opencode-no-hedging

[English](#english) | [中文](#中文)

<img src="gpt-hedging-meme.jpg" alt="GPT Hedging" width="420" />

## English

An ASD-STE100-style prompt for OpenCode (`SKILL.md`) and `AGENTS.md`. It targets defensive writing in English and Chinese across models, including GPT and Codex, while preserving evidence, meaning, and material uncertainty.

Use `Custom-Instructions-ChatGPT-Web` for ChatGPT web Custom Instructions.

## 中文

适用于 OpenCode（`SKILL.md`）和 `AGENTS.md` 的 ASD-STE100 风格提示词。减少 GPT、Codex 等模型的中英文防御性写作，保留证据、原意及必要的不确定性。

ChatGPT 网页版自定义指令使用 `Custom-Instructions-ChatGPT-Web`。
